Gmail Tracker Setup

Auto-sync your outreach emails with your Application Tracker

← Back to Application Kit

This connects your Gmail to a Google Sheet so you can automatically track every email you send to studios and employers. Takes about 10 minutes to set up, then it runs on its own.

What You'll Get 10 min setup

A Google Sheet that automatically logs every outreach email you send, with columns for: Date, Company, Subject, Status. It checks your Sent folder every hour and updates itself.

    Create a Google Sheet

    Go to sheets.new and name it "Job Outreach Tracker".

    Add these headers in Row 1:

    Date Company To Subject Status Notes

    Put each word in its own column (A1 through F1).

    Open Apps Script

    In your Sheet, go to Extensions > Apps Script. This opens the script editor.

    Delete any code that's already there.

    Paste this script

    Copy the entire code below and paste it into the Apps Script editor:

    function logSentEmails() { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var lastCheck = PropertiesService.getScriptProperties().getProperty('lastCheck'); var searchDate = lastCheck || 'newer_than:1d'; // Search sent emails - adjust the search terms to match your outreach var studios = [ 'buck.co', 'andwalsh.com', 'mvsm.com', 'pentagram.com', 'basedesign.com', 'tendril.studio', 'ordinaryfolk.co', 'themill.com', 'superside.com', 'unit9.com', 'deptagency.com', 'instrument.com', 'framestore.com', 'dneg.com', 'greenhouse.io', 'lever.co', 'workable.com', 'designremotejobs.com', 'danthree.studio', 'mercury.com', 'vercel.com', 'automattic.com', 'metalab.com', 'cosa.vfx', 'reelgood.com' ]; // Also search for keywords in subject line var keywords = ['application', 'portfolio', '3D motion', 'houdini', 'product animation', 'interested in the role']; var threads = GmailApp.search('in:sent ' + searchDate); var existingSubjects = getExistingSubjects(sheet); var newRows = []; for (var i = 0; i < threads.length; i++) { var messages = threads[i].getMessages(); for (var j = 0; j < messages.length; j++) { var msg = messages[j]; if (msg.getFrom().indexOf(Session.getActiveUser().getEmail()) === -1) continue; var to = msg.getTo(); var subject = msg.getSubject(); var date = msg.getDate(); var uniqueKey = subject + '|' + to; if (existingSubjects[uniqueKey]) continue; // Check if this email matches our studios or keywords var isMatch = false; var company = ''; for (var k = 0; k < studios.length; k++) { if (to.toLowerCase().indexOf(studios[k]) !== -1) { isMatch = true; company = studios[k].split('.')[0]; company = company.charAt(0).toUpperCase() + company.slice(1); break; } } if (!isMatch) { var subjectLower = subject.toLowerCase(); for (var k = 0; k < keywords.length; k++) { if (subjectLower.indexOf(keywords[k]) !== -1) { isMatch = true; company = extractDomain(to); break; } } } if (isMatch) { newRows.push([ Utilities.formatDate(date, Session.getScriptTimeZone(), 'yyyy-MM-dd'), company, to, subject, 'Sent', '' ]); existingSubjects[uniqueKey] = true; } } } // Write new rows if (newRows.length > 0) { var lastRow = Math.max(sheet.getLastRow(), 1); sheet.getRange(lastRow + 1, 1, newRows.length, 6).setValues(newRows); } // Update last check time PropertiesService.getScriptProperties().setProperty( 'lastCheck', 'after:' + Utilities.formatDate(new Date(), Session.getScriptTimeZone(), 'yyyy/MM/dd') ); } function getExistingSubjects(sheet) { var data = sheet.getDataRange().getValues(); var subjects = {}; for (var i = 1; i < data.length; i++) { subjects[data[i][3] + '|' + data[i][2]] = true; } return subjects; } function extractDomain(email) { var match = email.match(/@([^>]+)/); if (match) { var domain = match[1].split('.')[0]; return domain.charAt(0).toUpperCase() + domain.slice(1); } return 'Unknown'; } // Run this once to set up the hourly trigger function setupTrigger() { // Remove old triggers var triggers = ScriptApp.getProjectTriggers(); for (var i = 0; i < triggers.length; i++) { ScriptApp.deleteTrigger(triggers[i]); } // Create hourly trigger ScriptApp.newTrigger('logSentEmails') .timeBased() .everyHours(1) .create(); Logger.log('Trigger set up. Will check sent emails every hour.'); }

    Save and run the setup

    1. Click the Save icon (or Ctrl+S)

    2. In the function dropdown at the top, select setupTrigger

    3. Click Run

    4. It will ask for permissions. Click Review Permissions > Allow. This lets the script read your sent emails and write to the sheet.

    Run it once manually

    Change the function dropdown to logSentEmails and click Run.

    This scans your sent emails from the last day. Any matching outreach emails will appear in the sheet.

That's it. You're done.

The script runs every hour automatically. Any email you send to a studio or with job-related keywords in the subject line will be logged to your Sheet.

To add more studios: edit the studios array in the script.
To add more keywords: edit the keywords array.

Tip: After sending each outreach email, update the Status column in your Sheet (Sent > Replied > Meeting > Hired / No Response). The sheet becomes your CRM.
